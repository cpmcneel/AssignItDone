# Spring AI Tutorial

This folder contains code from a Spring AI tutorial completed by Connor for our AssignItDone project.

The tutorial was used to explore how Spring AI can connect a Java Spring Boot application to an AI model through Ollama. Connor completed the tutorial and pushed the code to the Experiments branch so the team could review it.

## Technologies Used

- Java
- Spring Boot
- Spring AI
- Ollama
- Maven

## Running the Project

The project uses Ollama for AI model access. To run it, create an API key at https://ollama.com/ and configure the API key and model in a local .env file.
